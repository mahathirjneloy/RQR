# RQR 📱

### Simple. Fast. Lightweight.

RQR is a minimal, super-fast, and lightweight QR code scanner for Android, built for one thing — **scanning QR codes quickly without unnecessary clutter.**

## ✨ Features

- ⚡ Super-fast QR scanning
- 📱 Minimal and clean interface
- 🪶 Lightweight
- 🔒 Privacy-focused
- 🎯 Simple and easy to use
- 📷 Uses your device camera
- 🚫 No unnecessary features or clutter
